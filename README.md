ChronosMatch: Zero-Copy High-Frequency Trading Engine

ChronosMatch is a low-latency High-Frequency Trading (HFT) simulation engine built using Python, Cython, mmap, asyncio, and curses.

The project demonstrates how high-throughput financial orders can be ingested, shared between processes using a zero-copy memory-mapped ring buffer, processed by a Cython-based matching engine, and monitored through a real-time terminal dashboard.
